# log1p 极值尺度诊断（2026-10-22）

使用当前两套分布的5000条未做幅值过滤的合成pilot，在合成数据上拟合统计量。real只用于报告变换后的范围，未参与拟合。高幅值组以当前门控max(2×real最大值,2)识别，仅用作诊断分组，不丢弃数据。

高幅值组：533/5000。与上一报告“任一变量超过两倍real最大值”的576条定义不同，本诊断还应用了门控的绝对下限2，因此是533条。

## 基线平方误差贡献

基线预测是各变量在对应变换空间的合成均值；该试验只衡量尺度效应，不是神经网络训练后的loss或real精度。

| 空间 | 高幅值组误差占比 |
|---|---:|
| 原始物理空间MSE | 91.912% |
| log1p空间MSE | 22.490% |
| log1p+逐变量Z-score MSE | 25.096% |
| 当前hybrid_mse_rel（均值预测基线） | 22.691% |

## 实现核对与限制

Y使用log1p(max(y,0))后逐变量标准化，P仍是线性Z-score。当前HybridMSERelLoss = 标准化空间MSE + 0.2×标准化空间RelativeL2；其relative分母并非物理轨迹能量。

同一个变量跨越很大范围时，近零绝对信号仍可能比高幅值变化更难学习。逐变量标准化能保护整体都很小的变量，却不能完全解决同变量内部的多尺度与多模态。保留高值后重算std还会改变小信号的有效权重。

所有结果为预处理/损失尺度诊断，未训练模型，不能据此断言real预测改善或恶化。训练对照应控制初始集、候选、随机种子、样本预算与统计量政策，并分别报告real整体、坏例和不同幅值区间。冻结统计量与逐轮重拟合必须区分，不应与幅值过滤同时变更后混合归因。

归一化、损失、训练入口均未修改。变量统计在variable_scaling.csv，完整拟合统计在statistics.npz，误差占比在summary.json。
