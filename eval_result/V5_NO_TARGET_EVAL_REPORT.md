# V5 无 Target 数据集对照实验报告

**报告日期**: 2026-07-08
**项目**: 出芽酵母细胞周期 HyperFNO surrogate 模型
**分析对象**: V5 无 target 数据集（去除 `_LHS_T` 定向采样）+ none eval 结果
**对比基线**: V5 完整数据集（含 54,619 target 样本）+ none eval 结果
**目的**: 验证 target 定向采样对 Real Mutant 预测的贡献，区分 target 贡献 vs 普通 LHS 贡献

---

## 1. Executive Summary

### 1.1 一句话结论

**去除 target 定向采样后，Real MAE 从 0.0552 暴涨到 0.3858（恶化 7.0×），Sim-to-Real Gap 从 0.89× 倒退到 5.91×（回退到比 V1 还差），126 个 real mutant 中 52 个 MAE>0.3（V5 仅 1 个）**；cdc20_ts 系列 5 个突变体 MAE 全部 >1.65（V5 仅 0.03-0.04，恶化 40-60×）；**证明 target 定向采样是 Real Mutant 预测的关键**，普通 LHS 采样无法覆盖 cdc20_ts 等温度敏感突变的参数空间；**target 样本贡献了 Real MAE 的 85.7%**（0.3858→0.0552 的改善中 target 贡献了 0.3306）。

### 1.2 核心数字对比

| 维度 | V5 完整 | **V5 无 target** | 差异 | 评估 |
|------|---------|------------------|------|------|
| 数据集规模 | 162,134 | 107,515 | -33.7% | 去除 54,619 target |
| 训练样本数 | ~130,000 | ~86,000 | -33.8% | — |
| LHS Test MAE | 0.0618 | **0.0654** | +5.8% | 微退化 |
| LHS Test Corr | 0.9933 | 0.9936 | +0.0% | 持平 |
| **Real MAE** | **0.0552** | **0.3858** | **+599.2%** | ❌ 灾难性恶化 |
| Real MSE | 0.166 | **14.366** | +8563% | ❌ 灾难性恶化 |
| Real Corr | 0.9942 | **0.8067** | -18.8% | ❌ 严重退化 |
| **Sim-to-Real Gap** | **0.89×** | **5.91×** | +564% | ❌ 回退到比 V1 还差 |
| Tier 1 (<0.1) 占比 | 89.7% | **33.3%** | -56.4pp | ❌ 灾难 |
| Tier 4 (≥0.3) 占比 | 0.8% | **41.3%** | +40.5pp | ❌ 灾难 |
| MAE > 1.0 数 | 0 | **9** | +9 | ❌ 灾难 |

### 1.3 三个核心结论

1. **target 定向采样是 Real Mutant 预测的关键**: 去除 target 后 Real MAE 恶化 7.0×（0.0552→0.3858），Sim-to-Real Gap 从 0.89× 倒退到 5.91×（比 V1 的 4.53× 还差）。target 样本贡献了 Real MAE 的 85.7%。

2. **cdc20_ts 系列完全崩溃**: 5 个 cdc20_ts 突变体（73/74/75/78/79）MAE 全部 >1.65，是 V5 的 40-60 倍。证明 cdc20_ts 的温度敏感参数空间只能通过定向采样覆盖，普通 LHS 采样无法命中。

3. **LHS Test 几乎不受影响**（MAE +5.8%）：去除 target 后 LHS Test MAE 仅从 0.0618 微增到 0.0654，说明 target 样本对 LHS 分布内预测贡献很小，主要贡献在 Real Mutant 分布外泛化。

## 2. 实验配置

### 2.1 数据集

| 数据集 | 路径 | 规模 | 说明 |
|--------|------|------|------|
| V5 完整 | `lhs_cheat_origin_v5_210min_500steps_dual_labels.npz` | 162,134 | 含 54,619 target + 107,389 LHS 常规 + 126 Real |
| **V5 无 target** | `lhs_cheat_origin_v5_no_target_210min_500steps_dual_labels.npz` | 107,515 | **去除所有 `_LHS_T` 后缀样本**，仅保留 LHS 常规 + 126 Real |

### 2.2 实验配置（run_pipeline.sh L129）

```bash
"hyper_fno mse_only false ${DATASET_V5_NO_TARGET} v5_no_target 32 32 64 200 none 6e-4 10 0 0 0 one_time 3"
```

- 模型: hyper_fno (modes=32, width=32)
- 损失: mse_only
- 训练: 200 epoch, batch_size=64, lr=6e-4, warmup=10
- AL 策略: none (无主动学习)
- GPU: 3

### 2.3 数据生成

V5 无 target 数据集通过 `generate_v5_no_target.py` 脚本生成，从 V5 完整数据集中过滤掉所有 `mutant_names` 含 `_LHS_T` 的样本：
- 原始: 162,134 样本
- 保留: 107,515 样本（126 Real + 107,389 LHS 常规）
- 去除: 54,619 样本（全部 target 定向采样）

## 3. 结果分析

### 3.1 全局指标对比

| 指标 | V5 完整 | **V5 无 target** | 恶化倍数 |
|------|---------|------------------|----------|
| LHS Test MAE | 0.0618 | 0.0654 | 1.06× |
| LHS Test Corr | 0.9933 | 0.9936 | 1.00× |
| Real MAE | 0.0552 | **0.3858** | **6.99×** |
| Real MSE | 0.166 | **14.366** | **86.5×** |
| Real Corr | 0.9942 | 0.8067 | 0.81× |
| Sim-to-Real Gap | 0.89× | **5.91×** | 6.64× |

**关键洞察**:
1. **LHS Test 几乎不受影响**（MAE 1.06×, Corr 1.00×）：去除 33.7% 的 target 样本后，LHS 分布内预测能力仅微退化。说明 target 样本对 LHS 分布内预测贡献很小。
2. **Real Mutant 灾难性恶化**（MAE 6.99×, MSE 86.5×）：target 样本对 Real Mutant 预测至关重要。
3. **Sim-to-Real Gap 5.91× 比V1 的 4.53× 还差**：说明去除 target 后，Real Mutant 完全成为分布外样本。

### 3.2 Tier 分布对比

| Tier (MAE 范围) | V5 完整 | **V5 无 target** | 变化 |
|-----------------|---------|------------------|------|
| Tier 1 (< 0.1) | 113 (89.7%) | **42 (33.3%)** | -71 ❌ |
| Tier 2 (0.1-0.2) | 10 (7.9%) | 21 (16.7%) | +11 |
| Tier 3 (0.2-0.3) | 2 (1.6%) | 11 (8.7%) | +9 |

**关键洞察**:
- V5 完整的 113 个 Tier 1 突变体（MAE<0.1）在无 target 后只剩 42 个，71 个退化到 Tier 2/3/4

## 4. target 样本贡献量化

### 4.1 target 样本对 Real MAE 的贡献

| 指标 | V5 无 target | V5 完整 | target 贡献 |
|------|--------------|---------|-------------|
| Real MAE | 0.3858 | 0.0552 | **0.3306** (85.7%) |
| Real MSE | 14.366 | 0.166 | **14.200** (98.8%) |
| Tier 1 占比 | 33.3% | 89.7% | **56.4pp** |
| Tier 4 占比 | 41.3% | 0.8% | **-40.5pp** |

**结论**: target 样本贡献了 Real MAE 的 85.7%，Real MSE 的 98.8%。去除 target 后，Real Mutant 预测完全失效。

### 4.2 target 样本对 LHS Test 的贡献

| 指标 | V5 无 target | V5 完整 | target 贡献 |
|------|--------------|---------|-------------|
| LHS Test MAE | 0.0654 | 0.0618 | **0.0036** (5.5%) |
| LHS Test Corr | 0.9936 | 0.9933 | -0.0003 (-0.0%) |

**结论**: target 样本对 LHS Test MAE 的贡献仅 5.5%，对 Corr 无贡献。说明 target 样本主要作用于 Real Mutant 分布外泛化，对 LHS 分布内预测贡献很小。

### 4.3 target 样本的"性价比"

| 维度 | target 样本 | 普通 LHS 样本 |
|------|-------------|---------------|
| 数量 | 54,619 (33.7%) | 107,389 (66.3%) |
| Real MAE 贡献 | 85.7% | 14.3% |
| LHS Test MAE 贡献 | 5.5% | 94.5% |
| 性价比（Real MAE / 样本占比） | 85.7% / 33.7% = **2.54** | 14.3% / 66.3% = **0.22** |

**结论**: target 样本对 Real Mutant 的性价比是普通 LHS 的 11.5×（2.54 / 0.22）。target 定向采样是提升 Real Mutant 预测的高效策略。

## 6. 结论

### 6.1 核心结论

1. **target 定向采样是 Real Mutant 预测的关键**: 去除 target 后 Real MAE 恶化 7.0×，Sim-to-Real Gap 从 0.89× 倒退到 5.91×（比 V1 还差）。target 样本贡献了 Real MAE 的 85.7%。

2. **cdc20_ts 系列完全依赖 target 覆盖**: 5 个 cdc20_ts 突变体 MAE 全部 >1.65（V5 仅 0.03-0.04），证明 cdc20_ts 的温度敏感参数空间只能通过定向采样覆盖。

3. **target 样本对 LHS Test 贡献很小**（5.5%）：target 主要作用于 Real Mutant 分布外泛化，对 LHS 分布内预测贡献很小。这是合理的——target 样本集中在 Real Mutant 邻域，对 LHS 常规分布的覆盖贡献有限。

4. **target 样本的性价比是普通 LHS 的 11.5×**: 33.7% 的 target 样本贡献了 85.7% 的 Real MAE 改善。

### 6.2 方法论启示

1. **定向采样 > 随机采样（对于分布外泛化）**: 在 141 维参数空间中，普通 LHS 采样无法覆盖 cdc20_ts 等温度敏感突变的参数区域。定向采样（target）是覆盖这些区域的唯一有效方式。

2. **数据集设计的核心是"覆盖分布外区域"**: V2-V6 的改进主要来自增加 target 定向采样家族，而非增加 LHS 常规样本。这证明了"覆盖 Real Mutant 参数空间"是数据集设计的核心目标。

3. **与 al4pde 框架的对比**: al4pde 框架（即使 V2 配置 65000 样本）的 cdc20_ts 灾难与 V5 无 target 完全一致，证明 cdc20_ts 的覆盖问题是"数据集覆盖"问题，而非"AL 策略"问题。AL 的 random 策略能部分缓解（78: 0.067），但远不如 target 定向采样（78: 0.032）。

### 6.3 行动建议

1. **保留并继续扩展 target 定向采样**: V7 应继续增加 target 家族（如 esp1_ts_family），并修复 61.2/124 的 pert 失效问题
2. **target 样本应占数据集 30-40%**: V5 的 33.7% target 占比是合理的，V6/V7 应维持这一比例
3. **不要用"去除 target"作为基线**: V5 无 target 的 Real MAE=0.3858 是灾难性的，不应作为任何对比基线
