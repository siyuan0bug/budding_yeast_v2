# Budding 逐基因/模式采样范围建议（2026-10-29，未实施）

本方案依据当前canonical real表、已完成的百万pool/70k train审计和26组新增ODE扫描。所有数值是**下一版的候选设计，不是已验证的生理边界或最优训练分布**。只新增用户要求的CLB2 GAL-MC表达方式，其余mutation类型保留；不以变量幅值设拒绝上限，不改变real定义、初值、ODE、环境规则或Fission。

## 1. 范围应按生效参数定义

MC比较拷贝/剂量，GAL比较绝对合成参数，ts比较残余活性，db比较残余降解。低降解和低活性的含义相反，不能统一套“real值×2”。同模式在多个real背景取值不同，须覆盖这些锚点并保留两侧探索。

建议先保留MA现有分布形状：MC基础权重1/N，GAL和正残余速率沿用对数均匀；修改有依据的支持区间。当前模块集合/模式均衡不意味着最终强度边际严格等于基础分布，有限容量/去重仍会改变频率。real条件之外并非自动非法，降低幅值范围也不保证改善FNO。

| CDC14 | 2 | 2～4 | 对30拷贝的偏离最明显，保留2→3→4的背景响应 |
| TEM1 | 5 | 2～8 | 围绕现有5拷贝条件保留探索 |
| CDC15 | 5 | 2～8 | 同上 |

| BCK2 | 5、10 | 2～15 | 同上 |

| PPX / ksppx | 0.2～0.6 | 无同模式real；WT=0.1 | 暂保持，明确为机理探索 |

**CLB2 GAL-MC单独表示为一个模块的复合等位型**，建议先忠实表达固定GAL构建体：

- GAL基底ksb2p=0.12；N为2～10整数，基础权重1/N。
- 生效ksb2p=0.12×N，即0.24～1.20；ksb2pp保持WT=0.04；mdt=150。
- N=8给出#50的参数作用形式，但完整输入与real相同仍须排除，不能把测试样本放回pool。
- 独立元数据保存GAL基底、整数N、生效参数；它们仍属于一个CLB2模块，不增加生物状态或模型参数维数。
- 不把普通MC规则叠加上去；普通MC会同时修改ksb2p/ksb2pp，执行顺序还会覆盖GAL赋值。
- 初版不自动再扩展成GAL-MC+db三重等位型。新增其他基因GAL-MC或更复杂复合类型需另有规则与范围依据。

固定GAL基底是#50的一种明确建模选择，不等同于已经知道真实构建体的所有表达变异。它带来**有限容量**：CLB2单模块、固定环境下N=2～10共9种输入；排除#50的N=8后只有8种，不能为了均衡给它硬凑几十条重复输入。以后若要增加基底连续变异，需明确其范围并对最终乘积约束，不能让旧GAL上限1.5再乘30。

## 4. ts、db、DAmP等：重点是残余定义与精确零

r为对应参数相对WT的残余比例。以下“精确零＋近零”建议先用50:50作为**提议分支权重**，正分支保持U(0,0.01)；有限容量耗尽后不能强行保证最终50:50，需要记录有效分布。不是将所有ts都置0，也不随机软化KO。

| 模式 | real生效条件 | 当前MA | 建议 |
|---|---|---|---|
| CDC20/APC_Core-ts | 对应合成通道为0 | r∈[0,0.01] | 加精确零分支，保留近零分支 |
| CDC15-ts | kkpnetpp=0 | r∈[0,0.01] | 同上 |
| APC-A | ka20pp=0 | r∈[0,0.01]，在赋值函数内部抽 | 同上；CDC20/APC_Core代理保持等效、去重 |
| CDC14-ts合成分支 | ks14=0 | r∈[0,0.01]，在赋值函数内部抽 | 同上；不改变它与活性分支现有50:50选择 |
| CDC14-ts活性分支 | r=0.10、0.16、0.30 | r∈[0.05,0.35] | 保持；四项活性必须共同缩放 |
| CLB5/SIC1/PDS1-db | 对应降解通道为0 | r∈[0,0.01] | 加精确零分支，保留近零分支；PDS1两项共同缩放 |
| CLB2-db | kdb2P=0；kdb2pp=0.034 | kdb2pp=0.0085～0.068 | **LogUniform(0.017,0.068)**，以0.034为几何中心，缩短更强的稳定化尾部；kdb2P仍0 |
| TEM1/ESP1-ts | r=0.002 | LogUniform(0.0005,0.004) | **LogUniform(0.001,0.004)**，以0.002为几何中心；保留原联动/总量/初值规则 |
| NET1-ts、TAB6-1 | r=0.05 | LogUniform(0.0125,0.1) | **LogUniform(0.025,0.1)**，以0.05为几何中心；两个结合参数共同缩放 |
| CLB2-pLOF | r=0.33 | U(0.1,0.5) | 保持，标注这是合并CLB1/CLB2后的模型设定 |
| DAmP | 无直接同模式real | clipped Normal(0.2,0.05)，0.05～0.4 | 暂保持；不能伪造基因级real依据；TEM1/CDC15仍无该模式 |
| CLN2/CLB2/PPX/Mcm1-ts | 无直接同模式real | 通用0.2×Beta(0.5,2) | 暂保持，单列机理探索；没有证据就不冒充“已校准”范围 |
| PPX-db | 无直接同模式real | r∈[0,0.01] | 暂保持，不将其他基因db的real条件强套为PPX实验依据 |
| KO、SIC1-PM、CDH1-CA、MAD2-CSL、BUB2-CKO、SBF_MBF-KO等固定修改 | 见当前赋值规则 | 固定参数/初值 | 保持；PM两项为0，不能为了减小幅值改成db或软PM |

精确零是输入条件覆盖要求，**不代表任意微小正值都会导致动力学相变**。下面新增扫描给出了平滑的反例，不能把连续分布几乎不取零直接等同于badcase根因。

## 5. 本轮26组诊断复算

四个CPU进程，原ODE/初始化/事件，rtol1e-7、atol1e-9、max_step0.25，210min/500点。所有26组成功；未用于训练。

- #124背景：APC-A残余r从0扫到0.01，CLB2峰值31.9539→30.9908，ORI峰值445.0685→431.6213，所有点仍为Pattern C。在这条扫描上响应平滑，不能宣称微小残余必然跨分岔。
- #29背景：SIC1-db残余r从0扫到0.01，SIC1峰值22.2088→17.8773，仍为Pattern C。极低残余接近零解，但残余1%也会改变积累幅值。
- #22背景：CLB5 2拷贝为Pattern C，4、6、8、12拷贝为Pattern B；建议2～6保留了观察到的两侧响应，不是只在real的4拷贝上堆点。尚未细定位临界整数/连续等效剂量。
- #15背景：CLN2 2、5、8拷贝的CLN2峰值均0.0652511。再次说明同拷贝数在不同背景的输出可以完全不同，收紧范围不能替代条件响应学习。
- #91背景：CDC14 2、3、4、8、30拷贝的CDC14峰值约1.2925、3.2896、5.2770、13.2569、57.2333；ORI峰值约54.16、0.797、0.098、0.096、0.092。缩到2～4仍保留显著响应变化，不必依赖30拷贝探索这一段。

这些扫描既没有证明所有新范围都正确，也没有证明FNO精度会提高。更多基因/复合背景仍需按新表采样后检查，尤其SWI5、无直接real校准的模式和稳定化复合。

## 6. 落地时必须同时处理的接口

1. 单一逐gene/mode范围表供随机抽样、Sobol逆CDF、模式内部随机分支共同使用；不能只改`distributions/mutant_aware.py`而漏掉quantiles或APC-A/TAB6/CDC14内部抽样。
2. MA为本方案的默认对象；静态MASS也需逐项对照最终生效参数。它目前MC是连续LogUniform的**等效剂量**，并非整数拷贝；若改成整数是额外语义变化，须明确采用的新分布，不能悄悄四舍五入。MASS的若干ts/db/APC-A固定赋值也不会随alpha范围自动变化，不借范围调整偷偷统一两套机制。
3. 枚举新GAL-MC模式，更新参数足迹、合法组合、描述/元数据与所有静态采样/AL入口；普通MC、GAL和GAL-MC明确区分，新增模式不能落入未知分支默认返回1。
4. `al_pool.finite_options`当前硬编码`range(2,31)`，`quotas.py`硬编码`29**MC数`，必须改为各基因实际支持集大小。新增精确零分支还要计入其有限容量，不能宣称仍是旧L1/L2/L3配额。
5. 碰撞救援沿用实际模块/环境保持与完整real排除，但必须从新范围抽强度；最终全局按生效输入去重，不能因两个标签不同放行同一物理输入。
6. 新规则应有内容指纹，旧pool/初始集与新分布不匹配时明确拒绝复用。用户可见文件名不必增加v2，但不能覆盖旧实验的来源文件或使旧checkpoint误配新数据。需要新生成pool和共享初始集，再由所有AL方法共用同一份。
7. 单独处理已确认8条TEM1总量越界；范围改变不能代替数值正确性修复。正式训练仍由用户启动；不宣称旧训练结果代表新方案。
