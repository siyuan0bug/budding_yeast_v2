# #7–10为什么预测较好，而#15预测很差？（2026-10-27补充核验）

**用户指出的反例成立：严格局部相似样本少，不能单独推出预测差；有很相似的输出轨迹，也不能保证模型在另一参数背景下会输出它。** 之前将badcase概括为“相似样本不足”过于宽泛。本次补充证据把输入局部覆盖、共享突变效应、输出相似性和模型的条件响应分开。

本报告使用用户给出的同一实验：FNO / al4pde_random / seed42 / round03 / 70000训练样本，参数为w192、n4、m24、b1024、最终200epochs。没有训练新模型、修改实验文件或改动采样分布。

## 2. #7与#9：并非没有近例，而且非常接近

- #7最近训练行 `MASS_RAND_CLN2[GAL-OE]+CDH1[KO]_L2_554109`，与real唯一的141维参数差别是ksn2p从0.120000到0.12006043，约0.050%。其完整39变量轨迹与real的RelL2仅0.000799。FNO对此训练行的RelL2约0.1180，对real约0.1180，二者几乎一样。
- #9最近训练行 `MASS_RAND_CLN3[GAL-OE]_L1_933606`，C0从real的2.000到2.006051，约0.303%。完整轨迹与real的RelL2约0.001127。FNO对此训练行与real的误差也很接近。

这两例具有很强的局部支持；几十条近例甚至一条极近的、动力学近似相同的例子，都可能比几百条仅名称相似的例子有帮助。这里不把极近样本称为精确重复，也不据此宣称训练测试泄漏。

## 3. #8与#10：局部盒内0条，也能从其他背景泛化

- #8是C0=0，#10是B0=0。只有单个输入参数改变，网络已经在包含这些KO的其他多模块样本上受过训练。
- 例如#8最近参数训练行是CLN3KO+CLB2pLOF，#10是BCK2KO+CLB2pLOF；这些输入不是相同real，但包含所需KO条件。
- 近参数不自动等于近轨迹：上述两条完整39变量轨迹与real的RelL2分别约0.590和0.642。反过来，按照旧审计9变量稀疏时刻特征找到的训练轨迹，与#8/#10的完整轨迹RelL2分别约0.141和0.127。

因此#8/#10预测好，无法用“严格盒内计数多”解释。证据支持模型在这些单KO条件上完成了跨背景泛化；具体哪些训练样本促成了这种能力，没有做移除样本后的重训，不能唯一确定。不要把该结论扩大成“所有L1都容易、所有L3都困难”。

## 4. #15：训练集其实见过几乎相同的阻滞输出

这是对上次解释最关键的补充。训练行：

`MASS_RAND_MAD2[CSL]+CLN3[KO]+BCK2[KO]_L3_10488`

其完整39变量轨迹与#15的RelL2只有 **0.000297**，比上面#8/#10所列动力学近例还接近；模型对此训练行的拟合RelL2约 **0.1306**，而对#15为 **6.8012**。

这条训练行与#15的主要参数差别为：ksn2pp=0.15而非0.75，同时Vi20_active=0.01而非8。**存在几乎相同的输出，不代表网络知道另一组输入也应该映射到同一输出。** 这不能称为完全没有P3/阻滞轨迹，更不能笼统称为“没见过类似轨迹”。

**直接观察：**

- 单独CLN3KO或BCK2KO、正常CLN2拷贝时，FNO误差约0.092/0.078，符合用户图中的好表现。
- 双KO、正常CLN2拷贝时，ODE与FNO都给出阻滞，FNO RelL2约0.119。
- 双KO背景把CLN2拷贝增至5，ODE CLN2峰值仍约0.06525、ORI峰值仍约0.09774；FNO CLN2峰值从0.725升到14.107，ORI峰值从0.205升到22.423，生成虚假启动及分裂行为。
- 在任一上游启动通路保留的背景中，5拷贝确实能带来明显CLN2信号；网络在双KO背景中仍输出这种趋势，反映错误的条件参数依赖。

模型方程中 `dCLN2/dt=(ksn2p+ksn2pp*SBF)*MASS-kdn2*CLN2`。ksn2pp的作用依赖SBF活性，不能在所有背景中无条件解释为更高的CLN2。**本次诊断明确验证的是模型在这一条件下的错误响应，而不是已经证明网络架构存在某个唯一缺陷。**

另将#15的BCK2或CLN3分别恢复到1%WT，ODE仍保持相近阻滞，FNO仍有约6.79的RelL2；有限残余邻域也会失败。因此不能把该错误全部归咎于“精确0这个点不连续/碰撞排除了精确real”。恢复到50%WT则出现明显动力学变化，说明此处仍需区分平坦区域与切换区域。

这些观测只适用于本次初值、参数及210分钟窗口，不能硬编码成“C0=B0=0时永远不能启动”。之前拷贝数扫描在30拷贝等条件下可产生其他动力学。

## 7. 对主动学习的实际含义

1. 候选数量、局部密度、全局P3数量都不能单独充当真实错误的充分解释或可靠评分。
2. 当前重点应包括：**发现模型在某个背景下对参数变化产生了错误响应**。对同一背景生成一组合法强度点，比不断换完全不同的背景可能更能暴露此错误；这是后续可验证设计，不是本次已经证明有收益的新算法。
3. 六分类有助于发现虚假分裂，但#15已有同P3输出而仍出错，只有补标签总量无法强制模型学会条件关系。
4. 扩充#15类的有效输入邻域仍是有依据的候选改进，但要与模型条件表达、损失/优化做固定预算消融，不能预先断言加数据一定全部解决。
5. 使用real结果设计采样规则属于development阶段；正式报告泛化增益需独立留出基因型/参数组合。线上AL不能直接读取本报告的real轨迹距离。
