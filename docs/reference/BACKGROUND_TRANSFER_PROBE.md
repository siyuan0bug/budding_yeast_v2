# 跨背景干预迁移：学习收益探针

当前为研究原型，不是已验证的新算法，也未加入正式批量suite。

## 生成与评分

从共同初始2000条已查询合成样本出发，按基因和合法mutation模式随机选择干预，强度仍调用当前原生分布。同一干预作用于8个不同的其他模块背景，替换已有焦点模块的干预，不构造四角，不修改mdt。移除旧干预涉及的参数/初值键，再由当前原生规则构造新输入；不同模块足迹重叠时不独立替换。GAL目标只使用原本mdt=150的背景。碰撞排除、去重、初值准备和ODE保持原规则。

已知锚点真轨迹记为a，模型预测的干预变化记为d。构造q=a+d，检查连续区间上的局部积分一致性：

`d(t+dt)-d(t) ≈ dt/2 * [(f(q,p_new)-f(a,p_old))_t + (...)_(t+dt)]`。

另检查d(0)是否等于原生实际初值的变化。逐变量尺度只来自初始训练轨迹的物理RMS，保护下限0.01；不使用real统计。事件屏蔽复用当前PRE检测，分别应用于已查询锚点和构造响应，不访问候选真实事件。非有限RHS或连续区间不足会记录为无法评分，不能当0分；对照也使用相同可评分域，报告有效比例。

每组取8个背景分数中位数，再按组排序，优先限制每种完整背景只入选一次。各背景实际效应可以不同；此处不假定效应相等。评分含物理残差成分，与PRE等有联系，尚未论证独立创新性。

## 实际学习收益验证

CLI：`scripts/analysis/probe_background_transfer.py`。

四组全部从同一个初始轮checkpoint出发：原2000条继续训练；增加256条全局随机合法样本；增加256条跨背景评分样本；增加256条同生成器随机组选样。共享生成候选、ODE成功标准和可评分集合。重合输入只仿真/保存一次；失败按既定政策用预排候选补足，所有尝试另报。新增轨迹分块保存，初始训练集及各组训练清单只引用源池。

独立探针：从源池训练侧候选中按独立随机流保留512条，排除初始集的全部模块/模式/mdt背景；最多每背景2条。这些背景也从新增候选中排除。探针标签只用于训练前后评估，不参与评分、拟合归一化、训练或checkpoint选择。真实测试/合成holdout轨迹不读取；holdout输入只用于统一碰撞排除。

诊断训练固定400个optimizer更新，batch128，AdamW学习率1e-4固定，梯度裁剪1；优化器在各组相同重置。使用已有YeastLitModule训练步骤、损失和共享Lightning执行器。仅诊断冻结原checkpoint归一化，避免归一化变化混淆采样增益，正式逐轮refit协议不变。最终固定更新评测，不取探针best。

预先声明的进入后续验证条件：跨背景评分组的归一化Relative比同生成器随机组改善超过2%，同时优于原数据继续训练；物理MAE相对同生成器随机组不能恶化超过5%。同时展示物理MAE、MSE、Relative、相关性等。通过仅说明值得进一步验证，不能代替完整多seed收益；未通过不直接启动长跑。

输出在外部`resource_profiles/background_transfer_probe_*/`：protocol、输入/选样清单、全部评分/失败记录、四组权重与训练记录、探针指标及report。不得与正式10k训练结果混排。

`--train-prepared`可复用已校验的共享初始行和新增块恢复到训练阶段，并校验数组及源码身份；不会再次调用ODE。只自动移除第一次更新前留下的空输出目录，不覆盖部分训练权重。CLI在CUDA初始化前设置`CUBLAS_WORKSPACE_CONFIG=:4096:8`以支持确定性训练。
