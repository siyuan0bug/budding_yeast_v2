# 下一采样方案草案：突变对照的输入依赖修复

状态：2026-11-24，R18局部虚拟更新中反馈改善未迁移；R19已实现固定评分的四组实际冷启动试训，正在后台执行。完整五轮采样器尚未验证，未开始新正式五轮实验。不是已验证的新方法或新颖性认证。主线仍为mutation池/合法mutation域，相同正式训练协议下超过Random、Power、LCMD。背景域消融暂不开展。

## 1. 假设与命名边界

暂称Mutation-Contrast Learning Design（MCLD，工作名）。要修复的对象是“从突变条件到完整轨迹的依赖关系”，而不是仅找某个输出误差大的点。

可证伪假设：选择能够提供尚未覆盖的合法突变对照、并对模型输入条件通路产生有效纠正方向的样本，比按单点误差、预测分歧或输出头特征选点，更能改善未见背景的完整轨迹预测。

依据是R15的行为观察：部分条件改变了真实动力学，模型却几乎输出常值。尚未证明内部表征已经坍缩，也未证明修复输入通路一定能改善泛化；这两点必须检查。

## 2. 与已失败路线的区别

|旧路线|已见局限|本草案必须做到的区别|
|---|---|---|
|R03局部路径加密|覆盖收缩，找到难点但无收益|对照仅是采集动作，最终批次要覆盖不同有效学习方向，不能长期围绕少数路径加密|
|R08组合梯度迁移|冻结pilot的输出头梯度sketch，无稳定收益|检查合法干预的差分学习任务及输入条件通路，不能仅换另一种输出描述|
|R14机制高误差|只看三个独立标量通道；去重差异很小|使用完整39变量真实响应，必须包括耦合结果；与随机对照提前核验实际选择差异|
|R16解析响应缺失|两选样组不同，仍无其余变量收益|错误幅度不直接当学习价值，要验证对应更新方向是否能改善其他背景的突变响应|
|旧Transport/Event|已包括saltation或事件描述|不把事件敏感性、模式熵换名重复提出|

这只是实质差异的设计要求，不是这些要求已经满足的结果。

## 3. 首版只做池选，减少不必要的不确定性

使用现有完整标注mutation训练侧候选，不读正式validation/test/real参与选择。先用真实完整轨迹检验“即使知道响应，能否设计出更好的学习动作”。这属于监督数据选择，需报告实际访问标签量，不能宣称只查询1万标签的AL。

- 输入为实际141参数、实际初值及原生mutation元数据。
- 连接能构成合法干预对照的候选：改变一个模块的合法模式/强度；其他模块的实际参数和环境条件保持。不同模块足迹重叠时拒绝独立解释。匹配条件及可用数量先审计，不靠放宽距离凑边。
- 首先允许固定已训练锚点加一个新端点，每个动作只占一条新增训练预算；没有锚点时查询两个端点占两条。预算按唯一新端点计，不重复奖励共享端点。
- 连续强度可以宽跨度，对照不强制局部邻近。生成版后续再接原生规则；首版不凭预测臆造候选真值。

## 4. 从单点任务变为“突变响应学习任务”

在每轮固定的共同训练统计坐标中，定义真实变化d_ij=Z(y_j)-Z(y_i)，预测变化dh_ij=F(x_j)-F(x_i)。用逐变量响应误差形成采集诊断。

不能只用||dh_ij-d_ij||排序，这会退回R16。需要计算该响应任务对输入条件参数块的梯度，并检查它与其他背景的响应任务是否能相互促进。

当前标准FNO的输入顺序是[初值, 参数, 时间]，通过lift卷积进入网络。首版可分别观察lift中参数/初值对应列和输出头的梯度，不改变模型或实际训练loss。仅靠换一个梯度层不构成创新：必须证明合法干预任务结构有额外作用。

选择端拟采用“响应任务的实验设计”：从训练侧独立背景构造一个固定的响应反馈任务集，选择能降低这些任务局部学习不确定性/梯度残余的端点集合，而不是寻找最大单点梯度。可先用低维梯度投影近似，记录投影误差与计算成本。

具体目标和求解器尚未定稿。D-opt、梯度匹配和双层选样都已有工作，不能随意选择其中一个后宣称全新理论。本草案真正待检验的是“合法突变响应任务＋输入依赖修复＋唯一端点成本”的联合设计是否提供额外价值。

## 5. 继续前必须回答的三个问题

1. 当前输入条件通路是否仍能获得可区分的梯度方向？若大量响应任务梯度几乎为零，或原模型不能学习这些差异，单纯换选样器可能不足，不能继续堆分数。
2. 与普通点梯度、输出头对照和同端点预算随机相比，响应任务选择是否真的不同？必须先报重合率、背景、模块及实际端点成本。
3. 在相同数据/初始化/学习率/更新预算下，选择方向是否改善未用于选择的完整背景？不能只改善已选对照或三条解析通道。

这些问题先在训练侧检查；这次没有启动又一轮400步试验。小试预算与停止条件在具体目标确定后声明，不能事后用最优seed或指标改判。

## 6. 公平性与失败判据

正式验证仍用2k/4k/6k/8k/10k、100/100/100/100/200epoch、batch128、FNO192/4/24、LR5e-4及既定逐轮refit/合成验证best规则。额外pilot、评分梯度和虚拟训练成本单列。

最低需要的机制对照：同候选域随机、普通单点高误差、普通梯度选择、去掉mutation合法关系的版本，以及已有Power/LCMD。首轮先检验核心差异，不立即批量铺满所有模型/seed。

如果只达到普通梯度方法同样效果，只作为任务适配，不声称独立算法；如果输入块与输出头无区别、真实响应信息仍不带来学习收益，停止该假设。不能将real名单、real误差或其特征频率用于反馈任务权重。

## 7. 必须区分的已有工作

- [CAL，EMNLP2021](https://aclanthology.org/2021.emnlp-main.51/)：已有对照样本采集思想；不能把“相似表征但不同输出”本身称新颖。
- [BADGE，ICLR2020](https://www.microsoft.com/en-us/research/publication/deep-batch-active-learning-by-diverse-uncertain-gradient-lower-bounds/)：已有梯度表示及批次多样性；不能把梯度范数＋多样性称为原创。
- [GLISTER，AAAI2021](https://ojs.aaai.org/index.php/AAAI/article/view/16988)：已有验证驱动的双层子集选择；不能把虚拟更新/验证收益本身称原创。
- 本仓库R08：已有跨背景、action条件化输出头梯度残余匹配；本方案若只是把头换成lift，差异可能不足。

已完成初步排重，不是完整文献新颖性检索。是否具有足够创新和效果，取决于后续精确定义、消融和实验；不承诺顶会或baseline胜出。

## R18诊断更新

输入通路有可区分的梯度，但当前反馈驱动选择没有在隔离背景检查获得收益。不直接扩大草案；后续若修订，需要新的可迁移任务假设及独立检查，不能靠本检查调参。见[研究记录](journal.md)与[R18报告](/home/users/zsy/mydata/budding_yeast/experiments/budding_sampling/summary/conditioning_gradient_probe_v1/report.md)。

## R19实际训练验证

R18仅八个端点与虚拟块更新，不能替代实际训练。R19不调整评分公式，改为四组各256条新增端点＋同一初始2000条，所有权重冷启动训练100epoch。四组为输入条件梯度、输出头梯度、同配对域随机、高误差；使用新背景的候选/反馈任务及512条隔离合成探针，各自训练集重新拟合统计，共同来源合成验证集选择best。候选及反馈共访问1280条标签，不能称只查询256条的AL。无新ODE，不读real或正式测试。

这是单seed、2256规模的单轮试训。按预先记录的物理Relative改善至少5%，且MAE/MSE恶化不超过5%的门槛，判断是否值得进一步验证。完成前不提前宣布有效；未通过不追加epoch或更换门槛。结果与当前运行状态以[研究记录](journal.md)为准。
