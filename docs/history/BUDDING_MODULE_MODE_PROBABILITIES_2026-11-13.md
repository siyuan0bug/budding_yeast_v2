# 模块、mutation与LHS-WT概率的口径

本轮只核对、解释和导出概率，不改变强度分布或采样概率。这里的主表是**LHS边际使用的新随机mutation提案**：均匀抽合法模块集合，再均匀抽该集合的合法完整模式组合。新完整池生产入口尚未迁移；这些数值不是旧AL池或已仿真数据集的实测频率。

## 三层概率

1. 模块阶数：L1/L2/L3有19/171/969个合法模块集合，总1159个；集合等概率意味着阶数概率1.63934426%/14.75409836%/83.60655738%，不是各1/3，也不是此前5/40/55。
2. 模块入选：每个模块参与1+18+153=172个集合，所以19个活动模块各自被选中概率172/1159=14.84037964%；每条提案平均2.819672131个模块。
3. 完整模式：给定模块集合后，均匀抽合法的完整模式赋值。包含跨模块冲突时，汇总到某个模块的条件模式概率可略不等额。

若对19模块对称且每条最多3个模块，平均模块入选率最多3/19=15.78947368%，平均未入选率至少84.21052632%。因此单个模块通常不变是稀疏mutation设计必然出现的结果。这个上界针对模块入选，不针对所有参数：APC_Core等会改变其他模块也触及的参数。

以上每行条件概率和为1；每个模块入选率都是14.84037964%。具体模式在整条提案中的概率＝模块入选率×本表条件概率。例如CDC6-DAmP=3.71009491%，CLB2-KO=1.85504745%，MAD2-CSL=14.84037964%。模块公平不等于每种mutation总体频次相同。

APC_Core/CDC20的偏差来自合法参数足迹约束，例如APC_Core-ts与CDH1两种模式都触及kscdh，不能在同一合法赋值中并存。因此“给定背景完整赋值等概率”不等于“所有背景汇总后每个模式严格等概率”。

完整状态与模式分量还要区分：CLB2单独GAL与GAL+db各12.5%，所以GAL分量出现概率是给定CLB2后的25%，整条提案中的3.71009491%；db分量同样25%。因此模式分量概率可以合计超过100%，不能当互斥概率表使用。

## ksb2p的87.0147% WT怎么来的

CLB2未入选的85.15962036%自然保持该参数；已入选但抽到单独db的1.85504745%也保持它，因为db只改降解。两部分相加87.01466782%。其他7个完整状态会改变ksb2p。

ksn2p更极端：只有CLN2-GAL会将其变成正值，其余模式即使改变CLN2其他参数，ksn2p仍为WT=0。因此其WT概率为1−14.84037964%×25%=96.28990509%。这不表示96%的样本没有CLN2干预。

LHS的45个混合模型参数保留这些单参数边际，预期每条有3.934713834个不同于WT；另外90个参数采用连续±50%窗口，理论上几乎处处不同于WT。所以每条LHS预期约93.934713834个模型参数不同于WT，不是87%的样本就是完整WT。参数变化个数不等于轨迹差异或覆盖质量；联合仿真仍待开展。

## 当前生产入口不能混用这些数字

mutant-aware profile定义强度和参数赋值，不独自规定模块/模式选择频率。

- 旧pure_random给定L后均匀抽模块、均匀抽基础模式，再执行25%合法复合扩展与冲突处理。CLB2此时先抽7种基础模式，各1/7，和新提案8种完整状态各1/8不同。
- 图策略共用common._sample_mode时默认按模式类别权重归一化；例如CLN2基础KO/GAL/MC各27.45098039%、ts17.64705882%。L1轮转及各策略自身模块选择还会改变汇总频率。
- 旧MASS随机路径仍读取catalog的参考权重；例如CLN2基础KO/GAL/MC/ts为66.7%/21.1%/3%/9.2%。新随机提案与LHS权重不使用这些参考数值。
- 旧AL参数池仍为容量感知均额配额＋Sobol，有限容量、别名和去重会影响最终计数，不适用上述新随机概率。

完整64单模式的旧入口基础概率已导出为legacy_base_mode_probabilities.csv；它们都是复合扩展/冲突/救援前概率，不是最终数据频率。

生成后必须另外报告模块、互斥完整模式、模式分量的实际计数，区分提案与接受频率。CDC20-KO/ts的有效输入可相同，APC-A两入口共享机制；不同名字也不等于不同有效输入，仍须统一去重。real救援、有限容量和数值失败拒绝均会改变最终频率。

## 是否需要降低WT质量

对稀疏mutation派生边际，当前高WT比例有明确数学来源，不是归一化错误。建议先保持mutation提案的模块/完整模式规则；若LHS目的是进一步拓展45个参数的变化率，可以独立设计其WT质量，但这将不再严格匹配mutation的单参数边际，必须明确标为另一种LHS设定，不能悄悄共改两者。仅凭87%不能确定当前LHS整体过于保守或预测效果不好，尤其另有90维持续扰动。
