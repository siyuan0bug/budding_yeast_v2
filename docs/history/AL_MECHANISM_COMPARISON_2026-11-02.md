# 2026-11-02 FNO主动学习方法对比与机制诊断

结论：新方法中Pattern Context最值得继续验证。其MSE在当前22种完整同预算方法中最低，但MAE/汇总RelL2尚未全面胜过Power；单纯类别平衡及当前敏感性/Event评分没有取得收益。所有结果仅seed42，不能当多seed稳定结论。

## 比较口径

统一FNO width192/4块/modes24、batch512、LR1e-3→1e-5、100/100/100/200 epochs、warmup5/5/5/10、四轮冷启动/累计synthetic train重拟合；同gene_ranges百万pool及初始10000/1250/1250+126。比较的是最后epoch，未按real挑checkpoint。旧research、optimized、Event修复和mechanism清单按旧到新优先合并；不完整旧实验及旧Event失败结果不参与。

## 为什么Context可以80株更好，但汇总更差

逐株对Power，Context有80/126株RelL2更低、76株MSE更低、68株MAE更低；Support分别78/66/60株。Context逐株RelL2中位数0.072848，Power为0.075024；但逐株均值Context0.127085、Power0.114087，少数退步抵消了多数小幅改进。

项目汇总RelL2不是126株RelL2的平均：`utils/metrics.py`先对每个变量合并126株×500点的误差/目标能量、加0.1物理地板，开方后再对39变量平均。逐株指标则分别使用各株目标能量。两者的分母与非线性聚合不同，不得混淆。MSE因每株维度相同，可等价为逐株MSE平均。

## 从已保存采集记录得到的诊断

以下都是查询完成后的synthetic分析，没有让采集器读取real真值，也没有新调用ODE。候选预先保存的概率/描述按candidate ID连接到accepted样本的随后真实分组；选中集的分类准确率有选择偏差，不代表全池无偏准确率。

1. **Balance：全局类数量接近平衡，但这一实现效果差。** 最终P1/P2/P3/P4/P5a/P5b为7895/13611/12270/11723/12730/11771；Power为4192/18201/5847/6191/26320/9249。Balance即使有12270条P3，#15 RelL2仍4.0948。只补全局分组数量不能替代具体突变背景和响应规律的支撑。不能据此断言所有类平衡方法无效。

2. **Context：局部真实证据有收益，预测分组仍有限。** 三次selected集辅助分类准确率67.97%/56.11%/55.58%；Support为68.34%/56.98%/53.28%。两个FNO成员在selected样本上也经常错分/打平。辅助概率不是可靠oracle，未来需要检验错分怎样影响核支撑。

3. **Support：添加预测动力学匹配未超过Context。** 第一次新增两方法8497/10000条相同，之后同轮交集11921/20000、14725/30000；最终Support的MAE/RelL2更差。预测轨迹描述可能带来错误相似性，但目前没有直接测量119维连续描述误差，不能仅由分类错误就证明该因果。

4. **Sensitivity：初值一致性项在部分轮次主导。** 第一批已选且分数为正的候选中，初值项占总平方分数的中位比例91.06%，80.16%的候选该比例超过一半；后两批中位比例分别8.34%、47.59%。因此当前分数并非稳定地主要衡量连续动力学响应违背。其6万accepted中38152条GAL-OE（63.59%）；这是分布偏向的观察，不能直接证明偏向导致了误差。其选样总开销约2小时03分，效果还不如Random，需要先拆项诊断。

## 下一步优先级

- 以Context作为研究主线，保留Power/LCMD与既有结果作参照。先做“保持相同背景核、支撑目标和贪心，仅去掉Pattern语义核”的消融，区分收益来自输入覆盖还是生物分组；核/贪心本身不是新发明。
- 单独检查模式背景共享及预测分组校准，修复应从synthetic查询反馈得到，不能为#15/#54等real身份设定采集权重。
- Support暂不能当默认增强；先验证预测描述可靠性，再研究其置信度处理。物理方向先分别评估初值项和连续动力学项，别继续把当前总分当成有效机理信号。
- seed42中的胜负和事后badcase归因不等于独立泛化结论。126 real参与过方法开发，仍需披露，并设计未用于开发的冻结评测及多seed验证。
