# seed42 补充 baseline 故障修复（2026-11-18）

本轮修复上一批失败的 HGGS、Lev、LHS Physics-PRE-Power，并补充 ERACS 机制可观测性。没有启动正式补跑，没有覆盖历史结果。旧批次的25完成/5失败仍是其真实状态；修复测试不能计作正式完成。

## 1. HGGS：跨轮刷新缓存被真值 Tensor 覆盖

`generation/policies.py` 的 `refresh(..., target)` 原本需要缓存目标总样本数，却在预测循环中把 `target` 覆盖为归一化真值。首次追加之后缓存变成张量，第二次追加与整数比较时触发歧义布尔错误。

现将真值变量独立命名为 `normalized_truth`，目标数验证为正整数。相同目标可复用刷新结果，不同目标重新计算已揭示训练数据的残差。读取旧策略状态时，错误的张量缓存会明确警告并失效；控制器、RNG和账本保留，下一次调用重新刷新。此迁移不绕过实验的源代码/配置校验。

新增测试覆盖连续多个预算、缓存重用、正常状态恢复、旧张量缓存迁移。真实 canonical ODE 小流程增加为三轮，并在第一轮追加后的评测阶段注入中断，再恢复并执行第二次追加，防止两轮测试漏掉该问题。

## 2. Lev：非有限打分导致重复选 ID

使用原正式训练侧90k输入、相同seed、相同分块与配额，在3号GPU单进程重放旧项目内核：

|池|输出槽位|旧实现唯一ID|修复后唯一ID|
|---|---:|---:|---:|
|mutation|10000|9996|10000|
|LHS|10000|9946|10000|

进一步定位旧实现 mutation 第80块、LHS第6块：float32矩阵分解/三角求解后1024个得分全部非有限，排序返回了先前选过、已被置为负无穷的ID。原代码没有在排序前检查非有限得分。另有先前CPU核查出现Cholesky非正定，均说明这一病态Gram矩阵路径不能继续依赖float32。

修复措施：Gram、ridge、Cholesky和三角求解统一float64；保留原 `1e-5` 正则和leverage公式；从索引域直接排除已选ID；最后一批只取剩余配额；检查得分有限及最终数量/唯一性。坏得分不随机补齐，也不赋零。诊断保存计算精度。测试将选择结果与直接ridge公式逐步核对，并覆盖秩亏、常数列、单点块和奇数预算。

这改变的是数值实现和合法ID约束，不修改酵母模型的参数、初值精度或训练精度。

## 3. Physics-PRE：事件屏蔽覆盖全部时间

以失败时LHS第3轮8000条训练所保存的checkpoint重推候选，定位到源池行ID **96195**。模型预测和canonical RHS均有限；其预测的事件信号变化密集，默认±4步屏蔽后没有任何合法三点差分模板。原异常将“无区间”和“非有限残差”混为一谈。

保留原事件检测及三点差分，新增显式的自适应额外padding：默认4；可用模板少于 `min(8,T-2)` 时逐步缩为3/2/1/0，尽量保留足够模板。**每个模板的三个点仍必须避开检测到的事件**，不是跨跳变求导。即使缩为0仍没有模板则报错；小于8但非零时使用剩余模板并记录数量。所有非默认窗口、候选ID及模板数量进入选择诊断。没有删除候选或读取候选真值。

残差非有限单独报错并列出样本ID；只有已屏蔽事件点上的非有限RHS会被掩去并计数，避免 `NaN * 0` 传播。额外修复了GPU checkpoint归一化统计读取至NumPy时缺少 `.cpu()` 的问题。

实际重放原失败追加：8000条训练参考、82000个剩余候选，成功选出2000个不重复合法ID。只有行96195使用自适应窗口0、留下22个安全模板；训练参考没有缩窗，屏蔽区非有限计数0。结果保存在探针目录，未写回原实验。

这一事件适配应在论文中明确说明，不宣称为原连续PDE实验的完全原样复现。未来若确实全时段无法定义连续残差，仍须明确诊断，不能静默修改候选可选域。

## 4. ERACS：不改阈值，明确“机制是否真的运行”

原两池均39次SNR检查、0次触发。`SNR < 0.1` 的实现符合当前声明的Algorithm1规则；没有触发本身不是软件异常。本轮不反转不等号、不根据real结果调阈值、不强制OMP。

每次检查现在同时保存阈值和触发公式；结束汇总 `selection_mechanism`：检查数、触发数、实际重选数、SNR范围、OMP机制是否执行。零重选时日志明确警告，避免把一次随机resident训练误解为已验证动态OMP收益。新增在默认阈值0.1下的合成梯度测试，实际验证高SNR不触发、低SNR触发并执行带权OMP及快照；恢复和完整小训练测试继续覆盖。

**待做的科研实验**：仅用训练/合成验证确定合适的SNR阈值及检查日程，再验证正式规模是否触发。历史ERACS的10k驻留与Random-Dynamic约89k历史曝光不等价，仍不能把两者误差差异全部归于重选算法。此处没有为了结果好看而改变协议。
