# 两个10万轨迹池的论文主对照建议

状态：用户已确认新mutation池采用1159个合法L1–L3模块集合等概率选择。本文件其余内容是论文实验设计建议，待审阅；没有修改已批准的90参数±50%配置，没有迁移生产入口或生成轨迹。

## 推荐的主比较

建议将主对照明确命名为“混合边际匹配的参数LHS（LHS-Matched）”与“Mutation-aware random sampling”。两者的候选池各为100000条完整、有效、唯一的合成轨迹；后续同一模型/选择算法最终训练10000条。固定范围和一维概率，包括WT/零点原子，主要考察保持生物干预联合关系的生成设计是否有效。

| 项目 | LHS-Matched | Mutation-aware |
|---|---|---|
| 45个可变模型参数 | 指定边际CDF的概率分层＋参数间随机配对 | 模块集合等概率、合法完整模式随机、既定强度分布 |
| WT/零点/整数/连续支持 | 匹配mutation提案的一维边际 | 使用既定mutation规则 |
| 同基因参数关系 | 不强制保留遗传构造关系；必要物理约束保留 | 同一mutation共享拷贝数/残余系数等 |
| L1–L3 | 无L或gene/mode标签；参数组合不必对应合法基因构造 | 每条1–3模块 |
| 90个背景模型参数（主建议） | 均固定WT | 均固定WT |
| 环境/初值/事件 | 共同边际、相同物理边界与canonical初始化；依赖结构差异明确说明 | 获批环境及初值/事件规则 |
| 输出/过滤/预算 | 与另一池相同 | 与另一池相同 |

此处比较的因素包括模块构造的联合依赖和LHS的边际分层方式，不能将结果声称为单独证明“参数相关性就是唯一原因”。LHS-Matched不是所有系数独立线性U(min,max)的普通盒域LHS，论文须准确命名，不能推广为对所有LHS设定的普遍优越性。

## 为何保留45参数的较高WT质量

LHS本身不规定WT概率。这里保留WT质量，是为了让主对照具有相同的单参数范围、幅度、零点与正常值频率，不新增一个随意选择的20%/50%WT超参数。公开全部141维分量表即可审阅其来源。不能为了追求更少WT，给LHS分配明显更多严重关闭或极端表达，再将不同任务难度的结果全部归因于采样设计。

McKay等原始LHS定义按各输入分布的等边际概率区间分层，并不要求所有物理参数值采用线性均匀：[原始论文DOI](https://doi.org/10.1080/00401706.1979.10489755)、[论文全文再版](https://www.asc.ohio-state.edu/statistics/comp_exp/jour.club/McKayConoverBeckman.pdf)。SciPy也明确在单位概率坐标做逐维分层：[官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.qmc.LatinHypercube.html)。

当前混合分布有离散原子，采用概率空间LHS再作广义CDF反演，必须明确这是混合边际设计；多个点映射到同一WT或零是正常的。原始蒙特卡洛估计方差结果不能直接当作神经算子训练精度保证。

## 当前更重要的混杂：90个背景参数

已配置方案的LHS对90个背景参数同时±50%，而mutation池固定这些值。两池即使同为10万，动态参数域和任务难度也不同，结果可能由背景扰动引起，不能单独归因于模块构造或LHS。

主建议是两池都固定90参数为WT：real评测在这些背景参数上也是固定模型值，符合当前突变泛化任务。这样LHS只对需要比较的非退化输入维度分层，仍导出相同141维输入契约。

此前±50%需求仍保留为备选，不擅自删除。若要研究背景不确定性，可以两池都采用同样90维U(0.5WT,1.5WT)，并把它作为共同背景扰动记录，区别于mutation本身。不要只扰动LHS一方，也不要仅为使主结论更好而挑选该设定。无需同时建立两套各20万的主实验；先确定一个共同背景协议。

## 评测协议

1. 两池均保存参数、实际初值、轨迹、BIO/ABC/中性六分组；mutation池另有实际mutation和L，LHS不伪造它们。ODE、网格、容差、超时与数值有效性规则相同；不因有限幅值较大、Pattern或不可存活而单方删样。
2. 说明“10万”是有效唯一轨迹数，并公开总尝试、数值失败/超时、real碰撞、去重与补采数。拒绝/补采后经验边际可能变化，需要报告WT/零点比例、分位数与Pattern分布；不能宣称最终池严格保留原始拉丁分层或两池经验边际完全相同。
3. 第一层生成范式LHS/mutation与第二层选择器Random/Uncertainty/BAIT/LCMD/ours等独立排列。同一池内所有选择器复用源池、初始化和固定holdout。两个不同源池不要求初始训练样本逐条相同，但初始化规则、样本数和种子协议相同。
4. 训练累计预算仍为2000→4000→7000→10000。参数和轨迹归一化每轮仅用已选合成train拟合；不同池的自己的train/val/test指标不能直接当同分布合成评测。固定real benchmark可共同评测；可预先从两池各保留等量合成测试行，组成共同测试集并从所有可选训练域剔除，额外报告分域结果，不需要第三个10万池。
5. 记录多个训练/选择seed；在同一份固定pool上重复运行可以评价训练/选择随机性，但不能当作多个独立生成池的重复。是否再加pool seed敏感性须另报，不把它们混在一个标准差里。
6. 论文公开范围和采样规则使用了文献/real基因型与参数先验；不能写成完全未利用benchmark知识。不得用最终real预测误差反调WT质量、阈值、配额或挑最佳seed。既有real坏例诊断属于开发过程，表述时不能宣称该benchmark始终完全未被查看。
7. 每池完整预仿真10万条，最终训练1万条。报告完整池仿真成本、训练数据量、选择开销及ensemble训练开销；不能将训练1万表述为只消耗1万次ODE查询，也不能沿用solver-in-the-loop AL的预算解释。AL4PDE的[原始论文](https://arxiv.org/abs/2408.01536)明确以查询数值求解器的设置为出发点，当前预仿真池属于不同成本协议。

## 可支持的论文结论

可检验的主张是：在预先声明的生物模型参数先验、同等生成/训练预算和共同评测任务下，mutation-aware生成及池内选样是否改善泛化与困难案例覆盖。两池生成范式差异、选择器贡献与计算成本分别报告。

仅有这两池不能证明所有LHS版本均不如mutation生成；也不能自动区分先验结构、边际分层与有效轨迹拒绝条件的独立因果贡献。若后续需要检验更通用的连续盒域LHS，可单独做范围敏感性/补充实验，不能通过主实验暗自改变LHS的先验或只挑不利设定。
