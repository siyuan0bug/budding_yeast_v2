# Mutant-aware sampling：面向生物 ODE 干预响应的通用采样研究

日期：2026-11-19。本文是研究设计，不是已实现功能、实测结果或原创性认证。当前 PRE 预测事件屏蔽保持原实现，不在本次修改范围内。

> 用户后续明确优先考虑跨生物系统泛化。当前方案据此调整：**手工 Pattern 不作为方法输入、采样配额或核心贡献；事件序列方向降为带事件系统的可选研究，不再推荐独立主线。**主线优先研究干预响应的机制反例与误差传播；连续、无分裂事件的生物 ODE 也应适用。下文保留事件方向的分析供溯源，不代表仍推荐以 Pattern 为中心。

> 后续用户授权已接入首版原型，实际入口、近似范围与 Fission 实验服务仍未贯通的边界见 [实现盘点](OURS_IMPLEMENTATION_AND_PORTABILITY_2026-11-19.md)。重新核查确认：旧 `ours_invariance` 已有 TEM1 精确不变性，旧 `ours_interaction` 已有四点查询。它们不能作为本轮新提出的研究贡献。

## 1. 建议研究的核心问题

不再把贡献限定为“按突变标签均衡生成一个池”，而研究：**如何使用已知干预规则与动力学机制，主动构造最有助于纠正代理模型错误的合法实验？**

可从固定池选择，也可在相同合法域生成新输入。方法不依赖 real mutant 名单、测试 Pattern 分布或测试误差。不要求两个系统使用相同蛋白名称、维度、初值、事件或 Pattern 标签。

单纯叠加 Power、Pattern、残差、距离的加权分数，或者固定六类等额，不足以构成本文希望追求的方法贡献。现有思想可以引用和使用，但必须说明新对象、新推导和新增算法分别是什么；“没有照搬 baseline 源码”不等于研究思想具有新颖性。

### 1.1 泛化对象与最小依赖

要迁移的是**采样算法**，不是要求两个系统共用一个预测网络或互相直接预测轨迹。Budding、Fission 各自训练代理模型，使用相同的查询设计准则和预算协议。

通用实验输入写作 `x=(合法干预描述, 强度, 环境)`；系统接口给出 `p(x), y0(x)` 与仿真输出 `Y(x)`。状态维度、名称、单位、时间轴均由系统提供，方法不包含 CLB2/MPF 等硬编码。初值不能作为任意独立可调输入，除非原系统协议本就允许。

- **共同基础：**合法干预提案/修改接口、实际初值处理、仿真器、已查询合成训练数据和代理预测；不依赖生物 Pattern 分类。
- **白盒机制版本：**额外使用已知 RHS 与干预到参数的映射，识别条件关系、估计响应/误差传播。不能把它宣传成只需黑盒仿真器的方法。
- **事件扩展：**系统提供 guard/reset 时加入事件传播；没有事件时使用普通连续 ODE 传播，不需要人为设置事件或新造 Pattern。
- **描述迁移：**只共用“哪个干预改变哪些方程/输入”的接口，不假设不同系统存在一一对应的基因、反应或标签。
- **评测侧：**Budding/Fission 原标签继续保留作各自诊断；删除、打乱或更名 Pattern 元数据应不改变通用采样器的结果。

参数/变量 Z-score、对数变换和强度分位坐标仅用于定义尺度与合法距离，不能代替跨系统方法贡献，也不能把逐坐标归一化后两个系统视为具有相同动力学。

## 2. 从当前代码核对出的共同结构与重要差异

统一抽象为系统 s 的合法编译器：

```text
模块/模式/等位分支 m，合法强度 u，环境 e
    → 现有系统规则
    → 参数 p、实际初值 y0、离散模式 q0、事件及重置规则
    → 规范仿真得到完整轨迹 Y 与事件记录 E
```

这里“编译器”只是现有规则的只读统一接口，不是新建一套 mutation 分布。

|对象|Budding 当前实现|Fission 当前实现|方法必须处理的差异|
|---|---|---|---|
|状态|39 维|16 维|输入/输出与尺度均由系统适配器提供|
|事件|CLB2、CLB2+CLB5、ORI、SPN 的有向阈值事件|START、SFINISH、DIV；START 还检查 RDNA 状态|事件判据、有效性条件和重置不能跨系统复制|
|初值|规范初值加突变专属修改|从 WT 出生态逐株预热；无分裂/异常等情形退回 WT 出生态|不能保持同一 y0 任意改变参数，也不能把预热当作免费操作|
|环境|GAL 与 mdt 有绑定规则|Growth 等使用自己的合法规则|不能从 Budding 的 mdt 规则推断 Fission|
|离散状态|Vi20、lte1、BUB2 等开关|START/SFINISH 会修改 kS|Fission 的 kS 切换应视为模式状态，不是全程常数参数|
|标签|生物标签、ABC、有限窗口六分类等|沿用其原有标签，包括 cut 等|算法可共用事件描述接口，不能替换 Fission 标签|

源码依据：`data/systems/budding/{ode,simulation}.py`、`data/systems/fission/{ode,simulation,states,phenotypes}.py`。Fission 质量输出还存在原始质量到论文相对质量的转换；机制计算与学习坐标必须明确单位。

目前 `utils/sampling/ours/offline.py`、`response.py`、`auxiliary/sensitivity.py` 存在 Budding 参数顺序、39 维、210 分钟或其事件等明确绑定。**当前已有 ours 不等于已经实现了 Fission 通用版本。**本次仅提出后续统一方法设计。

## 3. 方向一：机制约束下的反例采样

### 3.1 直观问题

同样提高一个模块的表达，在某个背景里会显著改变轨迹，在另一个背景里可能几乎无效。代理模型可能学到了“表达增加必然导致启动”这样的错误捷径；两个 ensemble 成员还可能一起犯错。

因此，我们不只问“模型对哪个点不确定”，而问：**哪一组合法干预使模型违反了可以从机制推出的响应关系？**

### 3.2 可验证的具体方法

1. 从训练输入与合法规则产生背景，枚举可变化的模块强度或模式；不扫描 real 身份。
2. 从 ODE 的反应项、约束和事件规则识别条件性无效方向。特别检查改变的参数是否只乘在一个能证明始终为零的状态/通量上。
3. 对精确关系，需要同时检查初值、可达不变集合、guard、reset 和模式变化。仅看静态因果图或某一时刻 RHS 为零不够。
4. 在这个关系允许的输入族中寻找模型预测差异最大的合法端点，可从池里找，也可按现有范围生成。
5. 按新增端点数计费查询规范 ODE；真实查询用于更新训练集与关系有效性记录。第一版仍用原训练损失，不额外增加配对损失，以隔离采样收益。

对于精确机制等价输入 a、b，若真实完整轨迹 Y(a)=Y(b)，则任意固定范数下：

```text
max(||F(a)-Y(a)||, ||F(b)-Y(b)||) ≥ ||F(a)-F(b)|| / 2
```

这只是三角不等式，不是新定理。价值在于如果能自动找到大量合法的条件等价关系，就可以在不知道候选真值时获得**至少一个端点出错的证据**，不需要 ensemble 分歧。

若已有严格响应上界 `||Y(a)-Y(b)|| ≤ δ`，则下界变为 `max(0, ||F(a)-F(b)||-δ)/2`。δ 只能来自可验证推导/包络，不能取两个已看过测试轨迹的经验差。有限个仿真对比只能支持经验关系，不能把它标为证明。

初版使用由训练集冻结尺度定义的统一加权轨迹范数；不能把上述绝对误差下界直接说成当前 sample/channel Relative L2 的下界。

### 3.3 与现有方法的区别及风险

- Power 比较成员对同一输入的预测分歧；本方向可用单模型违反机制关系的程度找错误。
- 旧 `ours_response` 已经使用对照对；仅把其 pair variance 改名不算新方法。
- 旧 `ours_sensitivity` 已有连续区间切向残差；本方向需要的是条件关系的有效域、可验证证据以及合法反例生成，不能把连续 JVP 重新命名。
- Metamorphic testing 已有“用输入关系检查输出一致性”的通用思想，需要引用。可能的新贡献是混合事件 ODE 中从干预规则推导条件关系，并将其变成有预算的纠错查询。
- 最重要的失败风险：可证明的完整轨迹等价关系可能很少。若跨两个系统关系覆盖太低、只能找到显然相同的输入，应该停止把它作为主线；不能拿“输出看起来相近”冒充机制证据。

**首个验证：**在独立合成开发任务上，统计关系数量、涉及模块/事件的覆盖率、反例分数与真实误差的关系，以及 ensemble 低分但机制反例高分的样本能否被稳定发现。

## 4. 方向二：动力学误差传播采样，事件作为可选扩展

### 4.1 为什么与 PRE 不同

同样大小的局部残差，在稳定连续段可能迅速消失，在临近某个事件时可能改变触发时间，随后影响整条轨迹。原始 PRE 的平均残差不能区分这两种情况。

研究目标是：**把局部方程、初值和重置缺陷，转换成对后续完整轨迹误差的估计，再选择/生成高价值输入。**

通用核心是连续 ODE 中的误差传播；带事件系统再附加下述跳跃传播。不能让算法必须依赖细胞分裂或某个特定事件才能运行。

### 4.2 拟采用的机制

令 `e = Y_hat - Y`。在事件序列一致且局部线性化有效的连续区间，近似满足：

```text
e_dot ≈ f_y(Y_hat,p) e + r
r = Y_hat_dot - f(Y_hat,p)
e(0) = Y_hat(0) - y0
```

跨事件需使用包含触发时间变化的敏感性传播，而不是仅乘 reset 的 Jacobian。可以基于 saltation matrix 构造传播算子，并纳入预测重置不一致的缺陷项。此处不是声称已推导完成；事件不对齐时如何组织误差，需要在实现前给出完整推导。

最终评分目标是训练尺度下整个时间区间的估计轨迹误差，例如 `integral ||W e_est(t)||^2 dt`，而不是只看终点或平均残差。W 只能由训练侧数据或预先指定物理单位确定。

实施时：

1. 模型预测提供候选路径；沿预测路径计算合法 RHS、guard、reset 的缺陷。
2. 用 JVP/小规模线性化或少量伴随探针估计误差传播，明确记录额外计算量。
3. 在当前合法域里选择高估计误差的输入或优化合法强度。
4. 查询后用真实轨迹检查估计器可靠性；只用训练侧反馈修正估计器。

**不能全域套用：**不同事件数/事件顺序、擦边触发、同时事件、分支边界、预热回退都是线性化失效区域。需要明确“估计适用/不适用”输出，失效区域使用独立事件反例处理；不能简单令分母接近零而无限提高分数。

Fission 的初值预热也会随参数改变。若估计的是参数响应，必须包含预热/出生状态依赖；不能默认 `dy0/dp=0`。仅估计某个已给定候选自身的轨迹缺陷时，其规范实际 y0 是已知输入，但获取该输入的预热成本仍须记录。

### 4.3 创新边界与验证

Saltation、混合敏感性、Fisher 设计和 Dual Weighted Residual 都是已有技术。已有 2026 工作讨论 salted Fisher，也有 DWR 引导 PINN 配点采样。**不能把“saltation + 信息矩阵”或“伴随加权残差”本身宣称首次提出。**

可能的贡献应是：面向混合事件**完整轨迹代理学习**，推导可用的输入级误差估计，给出失效条件，并据此设计混合离散/连续干预域的查询，而不是参数辨识或时空配点选择。

**首个验证：**构造局部残差相近但最终误差不同的合成样本，检查本估计是否优于 PRE 排序；比较无事件传播、仅 reset Jacobian、完整事件传播三种版本。如果只提高计算成本而没有更好的误差识别，停止扩展。

## 5. 方向三：事件序列的最小干预反例生成

**当前定位：可选的事件系统扩展，不再作为跨生物系统通用方法的主线。**事件提取比手工六分类少一些体系绑定，但仍不能直接覆盖没有离散事件的系统；这一限制不能仅靠更换事件名称解决。

### 5.1 从 Pattern 计数转向失败过程

两个样本可能同属“无分裂”，却分别是未 START、复制后未进入下一事件或退出失败。六分类只是有限窗口的粗摘要。算法可利用两个系统各自的事件记录，把过程表示为带时间的事件序列，并对没有发生的事件记录截至观察终点的删失信息。

例如 Fission 的 `START/SFINISH/DIV`，与 Budding 自己的四类事件，分别由各自模拟器解释。不能强制两者共用同一事件字母表，也不能凭期望的正常细胞周期顺序判定所有其他轨迹“非法”；Fission 的 cut 等本来就应保留。

### 5.2 拟采用的算法

1. 只用已查询的合成训练轨迹提取事件序列、首个分歧事件及有意义的机制上下文。
2. 在同一合法模式分支和环境下建立强度路径，寻找能改变首个分歧事件的最小合法干预；优先完成尚未获得两侧证据的局部事件对照。
3. 模型预测用于提出位置，真实 ODE 查询验证两侧事件是否真的不同；预测事件不当真标签。
4. 保存事件边界两侧与适量内部支撑点，检验是否学到了跨边界的完整轨迹映射，而不是只提高分类准确率。
5. 连续强度可做受限区间细化；整数拷贝使用合法相邻整数。不能把 KO 插值成一个未经允许的新 mutation；也不能越过 GAL/环境绑定。

这里“最小干预”是固定合法坐标/编辑代价下的搜索目标。大规模启发式搜索只能称近似最小，不能宣称全局最小。

候选池有合适端点就选择池内样本；没有就生成合法端点。生成不需要修改总体 mutation 支持，但自适应选点本来就会改变入选分布；必须报告这种选择偏置，不能称最终集仍严格遵循原先独立随机分布。

### 5.3 与既有工作的区别及风险

相图边界主动学习、bifurcation search、HGGS 边界采样及旧 `ours_pattern_*` 已存在。仅做 Pattern entropy 或在两类中间二分，不足以算新贡献。

潜在贡献需要落实在**事件首个分歧定位、合法干预路径、两侧见证与后续轨迹误差修复**上，并解释这比粗 Pattern 边界选点更好在哪里。

固定 210 分钟或其他有限窗口内少一次分裂，不等于发现真正分岔；无额外稳态/长期证据时使用“有限时域事件转变”，不用“鞍结”“极限环消失”等未经证实的结论。观察终点附近的事件缺失还需考虑时间窗删失。

**首个验证：**使用随机选定的合成背景，比较粗 Pattern 边界、事件熵、普通 HGGS 与最小干预事件对照；除了总体误差，还评测首个事件错误、分裂次数、时刻误差及转变两侧轨迹误差。未发生事件不随意补一个很大的时刻值。

## 6. 方向四：按组合效应的可辨识性补全干预实验

### 6.1 为什么不是多采 L3

想知道模型是否学会两个干预的联合影响，仅有一个 L3 轨迹往往不够。可以在合法共同背景 B 下组织四个实验：`B、B+A、B+C、B+A+C`，考察：

```text
I(A,C | B) = Y(B+A+C) - Y(B+A) - Y(B+C) + Y(B)
```

这是标准交互对比，不是新定义。**不假设 I 应当为零，也不把模型与加性预测的差异直接当成错误。**真实生物过程完全可能有很强交互。

### 6.2 需要增加的实际贡献

把采样动作设为“补全能够检验一个条件交互的实验组”，根据已有端点、真实已查询对比误差及预计新增成本，决定先补哪一组。一次新查询可以补全多个组，计算其实际边际价值；高阶组仅在低阶信息不能解释真实查询反馈时展开。

例如已知三个端点，新增一个即可验证交互；四个都未知则需计四条查询。不能对所有候选四元组先计算真实交互却仍声称没有读取它们的标签。

所有端点必须单独经过原合法规则：可选择一个非空背景后添加两个模块，使四角均在 L1–L3 域内；不为凑组生成不允许的 L0/L4。GAL 角落的环境绑定要在其他角落保持合法；每个角落分别计算其规范初值。四角差异因此是规范干预的总效应，不能忽略其初值变化后声称纯反应通量效应。

### 6.3 与已有方法的距离

本项目 `query_design.py` 已经有四端点交互分歧和边际成本。因此“从 pair 改成四元组”不是新贡献。本方向至少需要从“ensemble 交互方差”推进到**交互误差的可检验闭包、缺失端点价值、低阶到高阶的自适应展开**，并给出预算或可辨识性分析。

主动遗传交互发现与预测加性偏离已有相关工作。此方向生物解释较自然、工程上相对可控，但单独作为顶会主线的新颖性风险高于前两项，建议作为备选或必要对照。

## 7. 不接触测试样本的具体实验协议

1. 研究、阈值和筛选仅使用公共系统规则、训练侧输入、已查询合成轨迹，以及独立开发数据。规则不能从 real badcase 的 ID、参数或错误排名拟合得到。
2. 本项目此前已经多次查看 real badcase，不能再声称整个研究从未受该测试集启发。可以如实写“探索性观察提出问题”；正式版本冻结后增加独立合成组合/背景测试，real 作为已有外部参考，不再反复以它决定版本。
3. 独立测试按任务预先固定，可包含随机输入、未见模块组合、未见强度区间等；不能因某种拆分让 ours 好看才事后选它。开发/测试职责必须分开。
4. 生成服务集中做合法性、精确输入去重和保留集合碰撞检查。方法只收到接受/拒绝结果，不获得隐藏测试名单、标签或距离，也不通过反复试探该接口建立测试邻域。
5. 相同输入身份包括 p、实际 y0、离散开关和调度等，不能只比较参数向量。近邻通常不是自动泄漏；是否禁止近邻由预先定义的泛化任务决定，不能事后任意改阈值。
6. 使用 pool 内真实标签的 ours 版本应单列为完整标注池选择；不为消除信息差而偷偷把 Power/PRE 改成真值误差排序。
7. 主对比先保留相同代理模型/损失/训练协议，只改变采样。相同初始集、seed 和候选合法域；生成对照另匹配开放域随机查询。选样后每轮 train-only 归一化规则保持现协议。
8. 最终 10k、唯一标签、所有 ODE 尝试、warmup/前缀/额外延长仿真、敏感性计算、GPU/CPU时间和历史训练曝光分别记录。不能只按成功留下的最终 10k 声称生成开销相同。
9. 两个系统各用自己的初值、模式、标签与时间单位。要证明方法跨系统成立，优先在 Budding 开发侧冻结选择准则，在 Fission 上不通过其 real 测试结果调参；系统原生尺度和适配器的必要配置应披露。
10. 为支持更一般的混合系统贡献，除两种酵母，还可加入一个简单受控事件 ODE 作机制验证；不得修改两个原生系统使假设人为成立。

## 8. 优先级和先证伪的计划

|方向|最有价值的新问题|首个关键证据|主要失败条件|建议|
|---|---|---|---|---|
|机制反例|能否不用 ensemble 揭示共同捷径错误|合法、条件有效的机制关系覆盖与真实纠错收益|关系极少或不能验证|优先做廉价可行性审计|
|动力学误差传播|同样局部残差为何造成完全不同的完整轨迹误差|连续 ODE 与事件 ODE 中均优于局部残差；事件项另做消融|线性化失效多、开销远超查询收益|通用主线候选，事件处理作为可选扩展|
|事件最小干预|有限时域事件转变处是否缺关键支撑|优于粗 Pattern 分层/事件熵/HGGS 的转变对照|只适用事件系统，退化成已有边界采样|降为可选扩展，不再以 Pattern 为主线|
|交互实验补全|有限预算下如何学会条件组合效应|每个新端点的补全价值与组合泛化收益|与旧交互方差/已知 AL 区别不足|备选与重要对照|

不建议现在一次实现四套完整长实验。先做可证伪的小规模合成开发分析，特别检查前两项是否有机制覆盖或误差估计价值，再选择一条主线。正向结果不能保证顶会录用；需要更完整相关工作核查、方法贡献与多 seed 实证。

跨系统验收额外要求：移除 Pattern 输入、替换变量名/维度后算法正常运行；在至少一个无离散事件的生物 ODE 上验证基础准则；在 Budding 开发侧确定采样准则后，不用 Fission 测试结果另选公式或调权重。机制关系覆盖不足的系统须报告实际适用范围，不能声称对任意生物网络都能找到精确无效方向。

## 9. 本轮定向检索的关键已有工作

以下用于划定贡献边界，不表示已经完成穷尽式新颖性检索。

- Kong 等：*Saltation Matrices: The Essential Tool for Linearizing Hybrid Dynamical Systems*，2024 期刊版本信息见 [作者预印本](https://arxiv.org/abs/2306.06862)。混合事件敏感性是已有数学工具。
- Odunlami 等：*Salted Fisher Information for Hybrid Systems*，2026，[预印本](https://arxiv.org/abs/2603.29862)。仅在 Fisher 中加入事件敏感性不宜宣称为本项目新贡献。
- Govoeyi、Richter：*Goal oriented error estimation for adaptive sampling of PINNS*，2026，[预印本](https://arxiv.org/abs/2604.01835)。DWR 引导采样已有工作，原问题是 PDE 的目标泛函及域内配点。
- *Active search for bifurcations*，[论文 DOI](https://doi.org/10.1063/5.0226625)、[作者公开稿](https://bpb-us-e1.wpmucdn.com/sites.mit.edu/dist/6/1408/files/2024/06/24_chaos.pdf)。不能把发现动力学边界本身称为新想法。
- Gao：*Do Perturbation Predictors Learn Gene Interactions? Diagnosing Extrapolation in Agentic Screening*，2026 Workshop，[预印本](https://arxiv.org/abs/2610.18880)。与加性预测的偏离作为诊断已有工作，不能直接重命名。
- *Knowledge graph-aided Bayesian active learning for top-K genetic interaction discovery*，[论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12379194/)。主动寻找遗传交互并非新问题；需区分寻找 hit 与学习完整动态轨迹。
- Murphy 等：*Properties of Machine Learning Applications for Use in Metamorphic Testing*，[作者公开稿](https://www.cs.columbia.edu/wp-content/uploads/sites/7/2016/08/Murphy-SEKE2008.pdf)。关系一致性检查本身有长期前史。
- 本项目现有 baseline 的具体出处与任务适配见 `papers/baselines/sampling/BASELINE_SOURCE_FIDELITY_AUDIT_2026-11-18.md`，以及已有 `ours/response.py`、`ours/auxiliary/sensitivity.py`、`ours/query_design.py`；不得把现有实现当作新提出的独立方向重复计贡献。
